# Морфологический анализатор

---

### Основные модули 

Данная лабораторная работа использует функционал предыдущей, так что все основные структуры данных остаются прежними. 
Данный модуль был доволнен следующими классами:

- **CorpusDoc** - Представляет собой документ, который хранит текст и библиографические данные о нем. + предоставляет методы для получения статистики по запросу (в данном случае запрос - слово на естественном языке).
- **CorpusManager** - Реализует функционал менеджера корпуса, который выполняет CRD-операции над текстами, а также осуществляет сбор и вывод статистических данных по всем документам, которые хранит.
