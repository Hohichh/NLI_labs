# Морфологический анализатор

---

### Основные модули 

- **parse_rule_input.py** - парсинг пользовательского ввода морфологических правил для образования словоформ
- **lab1** - основные структуры хранения и обработки данных (входы - текст на естественном языке)
    - **Dictionary** - словарь, содержащий словоформу из оригинального текста (ключ) и соответствующую лексему
    - **Lexeme** - структура данных, хранящая морфологическую информацию о слове (лемма, часть речи, формообразующие окончания), + структуры для образования словоформ.

Для образования словоформ был разработан модуль грамматических правил **Rules**, который включает в себя слудующие классы:
- **Noun** - грамматика существительных
- **Verb** - грамматика глаголов
- **Adjective** - грамматика прилагательных 
- **Adverb** - грамматика наречий
Интерфейс генерации словоформы - метод .generate_form() - присутствует в каждом классе. Для исключений предусмотрены словари 
в формате csv в директории **Exceptions**
